Activities, projects, and habits are different axes.

An activity says what you did. A project says what it served. A habit says how often you want to return.

Generalize the arithmetic. Keep the meaning specific.

A small shared goal vocabulary

A scoped source, a metric, a unit, a target, a period, and eligible days support all four directions.

  • Remaining = max(0, target − completed).
  • Required pace = remaining / eligible opportunities remaining.
  • Next threshold = the next chosen rung above the total.
  • Active days = distinct eligible local dates that meet a stated minimum.
  • Consistency = completed eligible periods / closed eligible periods.

At the deadline, show “met” or a remaining gap. Never divide by zero. After crossing the target, retain the excess and celebrate it.

Domain adapters carry the rules

  • Exercise: sum reps for selected exercise IDs, with explicit variation rules.
  • Timers: closed intervals only; split at local boundaries and union overlaps within an activity.
  • Habits: one credit per habit per routine day, regardless of duplicate logs.
  • Reading: one edition’s position; distinguish a first finish from rereads.
  • Projects: attribute each interval once. Task count is not percent complete.

No universal life score. No sum of pages, reps, and minutes. No automatic intent inferred from a timestamp schema.

Use a goal’s stored timezone for stable period boundaries. Current timers can display separately as “in progress” until closed. Exclude deleted data and honor visibility settings. Label incomplete import coverage. Treat absent records as “no log,” not proof of inactivity.

Reading: buy proximity before buying speed. A single position answers “Can I finish this tonight?” Pages/hour mainly invites optimizing how fast you consume a book.

The page proposal assumes one physical edition per book entry. Multiple editions require an edition relationship and edition-specific length first. For audio, use optional reading-log/progress-percent within 0–100 or native audio position with duration; do not invent equivalent pages. If session page totals become a real goal, add explicit reading-log/pages-read; do not derive them from incomplete position history. Mark examples requiring new attributes clearly.

All additions are optional proposals, not schema patches. Keep existing production attributes unchanged. New entities need the standard owner and metadata fields and schema registration. Do not store derived remaining, averages, streak lengths, or dashboard scores on logs.

What I would deliberately leave out

A muscle map on the home screen

Roadmap 046 needs exercise-to-muscle mappings the current schema does not have. It explains distribution, but gives a weaker next action than “60 to 7,000.”

A lifetime grid as the main motivator

Roadmap 018 is useful for reflection. Twelve weeks of chosen practice make a clearer invitation for today than thousands of lifetime cells.

Automatic goals from generic charts

Roadmap 016 and the current viz routes can detect temporal data. They cannot infer which activity you want more of, or what counts as enough.

Visual and chart decisions

Keep Gleanmo’s dark surfaces and colored accents for pace, studio, and rhythm. Use a warm paper palette for the invitation board.

Each file has inline CSS, JavaScript, and SVG or HTML marks. Everything works offline when opened directly; there are no fonts, images, or chart libraries to fetch. Use ECharts for the production cumulative line, period bars, and calendar history. Keep oversized numbers, routine steps, and milestone receipts as HTML. They carry the motivating message more clearly than gauges.

Shared tokens: 4px spacing base; 6px controls and 12px panels; system sans with monospace labels; borders for depth; 44px controls. The paper direction uses Georgia headings. Layouts stack below 760px. All controls only manipulate fictional preview state.

First build: one honest finish line

Start with Pace lab for a single chosen goal: total, remaining, current average, required average, next threshold, and a cumulative line.

Use a period with complete capture. If exercise imports are pending, start with meditation minutes or a new pull-up goal beginning today.

Then use the same calculations to power Within reach. Add the studio when activity classification earns its capture cost.

The success signal is whether a visit makes you start something you wanted to do. More chart views alone do not establish that.
